# 开发过程记录

## 项目目标

完成川山甲战队视觉组正式队员考核方向一：基于 ROS 2、OpenCV 与
AprilTag 的单目三维视觉和增强现实系统。

## 2026-07-29：环境与基础框架

- 安装并验证 Ubuntu 22.04、ROS 2 Humble、Python 3.10 与 OpenCV。
- 创建 `apriltag_ar` ROS 2 Python 包。
- 建立摄像头发布、AprilTag 检测、launch 与 config 基础结构。
- 验证 USB 摄像头可由 V4L2 打开，并发布 `/camera/image_raw`。

## 2026-07-30：标定、检测与位姿

- 使用 640×480 图像完成单目相机标定。
- 最终内参为
  `fx=675.85100`、`fy=683.09268`、`cx=325.73900`、
  `cy=214.65946`。
- 最终畸变系数为
  `[0.181898, -0.521402, 0.005301, 0.005508, 0]`。
- 实现 AprilTag 36h11 检测、ID、P0–P3、CENTER 和三维坐标轴标注。
- 标签边长由早期测试值修正为外围正方形实测值 `0.0575 m`。
- 通过 `SOLVEPNP_IPPE_SQUARE` 估计位姿并发布 Pose 与 TF。
- 在 AprilTag 坐标系中加入固定三维偏移的悬浮 AR 立方体。
- 在 RViz2 中完成 TF、相机模型、标签模型和 MarkerArray 显示。

## 2026-07-31：延迟与稳定性优化

- 摄像头设置为 V4L2 + MJPG、640×480、30 FPS、缓冲区深度 1。
- 图像订阅与发布采用传感器数据 QoS，降低队列积压。
- 增加 `apriltag_direct` 直连模式，绕过 ROS 图像传输链路；最终内部
  处理速度约 26–27 FPS。
- 使用手动曝光和 50 Hz 防闪烁设置，减轻屏幕显示标签时的亮度闪烁。
- 使用 OpenCV 默认的 `DetectorParameters`，并通过位姿滤波提高移动过程中的跟随稳定性。
- 确认标签外围白色静区对正面检测很重要；纯黑背景稳定性较差。

## 距离验证

| 实际距离 | 测量距离 | 绝对误差 | 相对误差 |
| ---: | ---: | ---: | ---: |
| 15.00 cm | 15.05 cm | 0.05 cm | 0.33% |
| 18.00 cm | 18.63 cm | 0.63 cm | 3.50% |
| 20.00 cm | 20.30 cm | 0.30 cm | 1.50% |

相对误差按表中保留两位小数的测量距离计算。

约 10 cm 时摄像头无法正常对焦，导致标签不能稳定识别，作为失败案例保留。

## 最终数据流

1. USB 摄像头通过 V4L2/MJPG 采集 640×480 图像。
2. OpenCV 检测 AprilTag 36h11 并提取四角点。
3. 结合相机标定参数和标签实测边长估计三维位姿。
4. 发布 Pose、TF、MarkerArray 与处理后图像。
5. OpenCV 窗口显示检测与 AR 效果，RViz2 验证三维坐标关系。
